# Playwright Opencode

This repository contains Playwright automation scripts and examples for learning and testing web applications.

## Project Structure

- `JavaScript/`: Contains JavaScript-based Playwright scripts
  - `Chapter_01_Basics.js`: Basic introduction to Playwright automation

## Getting Started

1. Install dependencies: `npm install`
2. Run the scripts using Node.js: `node JavaScript/Chapter_01_Basics.js`

## Requirements

- Node.js
- Playwright
